# Лимиты подписки Claude Max

Проверено 2026-09-13 по справке Anthropic. Точных чисел Anthropic не публикует
принципиально: расход зависит от длины контекста, модели и включённых фич.
Фактическое состояние смотреть в **Settings → Usage** — прогресс-бары по
5-часовому окну и по неделе плюс время следующего сброса. Лимиты общие для
claude.ai и Claude Code.

## Три лимита

| Лимит | Что это | Числа |
|---|---|---|
| Окно 5 часов | сессионный лимит, сбрасывается каждые 5 часов | только кратность к Pro: Max 5x — ×5, Max 20x — ×20 |
| Неделя (7 дней) | поверх сессионного, общий для всех моделей | не публикуются; сброс в фиксированное время недели, назначенное аккаунту |
| Fable | доля недельного лимита | **до 50 % недельного лимита** на Max |

## Fable — единственное численно заданное правило

- На Max (и premium-местах Team/Enterprise) Fable 5 и Fable 5.1 входят в план:
  до 50 % недельного лимита на Fable без доплаты.
- Упёрлись в 50 % — либо продолжать на Fable за usage credits, либо
  переключиться на другую модель и доработать неделю в рамках плана.
- 50 % — потолок именно для Fable, но расход других моделей идёт из того же
  недельного лимита: суммарно больше недельного лимита не выйдет никак.
- На Pro и обычных местах Team Fable в лимиты не входит вовсе — только за кредиты.
- В Claude Code: Fable 5 требует версии ≥ 2.1.170, Fable 5.1 — ≥ 2.1.255.

Отдельного недельного суб-лимита на Opus в справке сейчас нет — только общий
недельный лимит плюс оговорка, что Anthropic вправе вводить дополнительные
ограничения по моделям и фичам.

## Следствие для правил выбора модели

Fable 5.1 соло на глубоких цепочках упирается не в деньги из `costs.md`, а в те
самые 50 % недели. Если гонять Fable как водителя сессии, половина недельного
бюджета уходит быстро, и остаток недели придётся жить на Opus. Правило
«Fable только на дорогих по решениям и дешёвых по чтению сессиях» из
`global/CLAUDE.md` этим и подпирается — не только ценой за токен.
