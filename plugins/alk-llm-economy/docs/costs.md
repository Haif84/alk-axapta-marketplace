## Панель `/usage` за 2026-09-17: из чего складывались сутки

Первый срез расхода не из наших скриптов. Панель считает проценты от лимитов
подписки, а её срезы — независимые характеристики одних и тех же суток, не
слагаемые: они пересекаются и в сумме больше 100 %.

Полосы на момент снимка: сессия 15 % на третьем часу из пяти (прогноз ~25 %,
запас), неделя 27 % на втором дне из семи (прогноз ~95 % — впритык), недельный
Fable 17 % при потолке 50 % (прогноз ~60 % своей полосы, но Fable тратит и
общую недельную, `docs/subscription-limits.md`). Узкое место — недельная
полоса, а не пятичасовая: резать надо цену единицы работы, не интенсивность.

Срезы:

| Срез | Доля суток |
|---|---|
| Плагин `superpowers` | 41 % |
| `superpowers:writing-plans` | 20 % |
| `verification-before-completion` | 7 % |
| `test-driven-development` | 3 % |
| `remember` | 2 % |
| brainstorming, claude-api, code-review | по 1 % |
| Сабагент `general-purpose` | 9 % |
| Сабагент `superpowers:writing-plans` | 9 % |
| Сабагент `tgbot-agent:tgbot-audit` | 1 % |
| `Explore` | ниже 1 % |

Проверка когерентности: 41 % плагина ≈ 31 % его скиллов + 9 % порождённых им
сабагентов — срезы сходятся.

Что панель подтвердила независимо от наших замеров: «82 % of your usage came
from subagent-heavy sessions» — ровно вывод `analyze-sessions.mjs`; `Explore`
ниже 1 % при `general-purpose` 9 % — правило «разведка через Explore» не
исполняется, потому что восемь промпт-шаблонов `superpowers` диктуют
`Subagent (general-purpose)`. Чего панель не видит вовсе: TTL кэша и разрывы
— там наши скрипты остаются единственным источником.

Что панель советует, а подтвердить не удалось: «heavy skills can be run with a
cheaper model via skill frontmatter». По всем установленным плагинам
`grep -rln --include='SKILL.md' '^model:'` даёт ноль файлов, `skill-creator`
называет обязательными только `name` и `description` — ушло в техдолг 27,
а не в правило.
