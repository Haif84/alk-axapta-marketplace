# Аудит промптов 2026-09-13 (`/claude-api prompt-audit`)

Повод: статья Anthropic о стоимости
(<https://claude.com/blog/reducing-cost-and-improving-performance-with-claude-platform>):
правила, написанные под старые модели, на новых тратят токены и портят
поведение; на поддержке чистка дала −14.6 % цены и +5.3 % точности; у Fable 5.1
шаг `high`→`max` на HLE даёт +0.5 п. за +46 %; Fable 5.1 `low` равна Fable 5
`high` за треть цены. Область аудита: `global/CLAUDE.md`, шаблоны,
`docs/agent-prompts.md`, хуки, `settings.json`. Целевые модели: Fable 5.1 и
Opus 5 водители, Sonnet 5 исполнитель.

Принято и сделано в этой сессии: порог контекста в токенах и хук
`context-budget.ps1` (коммиты `10d04cc`, `702a0c6`).

Чистыми признаны: `docs/agent-prompts.md`, хуки, шаблон `tech-debt.md`,
пятиминутный кэш сабагентов, правило «модель и effort до первого сообщения».

## Решение владельца 2026-09-13

Приняты ханки 1, 2, 4, 5, 6 и внесены в тот же день. Ханк 3 (context7 против
правила о справочных скиллах) отклонён: правило остаётся как есть, инструкция
сервера не оговаривается.

При реализации ханка 2 выяснилось, что коммит `c8939c6` кодировку не починил:
`ConvertTo-Json` в PS 5.1 кириллицу в `\uXXXX` не переводит, байты уходили в
CP866. Оба хука теперь экранируют не-ASCII вручную (`825ddc0`, `1d9f70e`).

## Ханки

Каждый независим; берётся выборочно. Правки `global/CLAUDE.md` — в конце
сессии, затем `.\deploy.ps1 -Apply`.

### 1. Дефолт модели и `/model` (уверенность высокая)

Правило называет дефолтом Opus 5, а `settings.json` хранит
`claude-fable-5-1[1m]`: `/model` записывает выбор навсегда, «дефолт» равен
последнему выбору.

```diff
-- Дефолт в settings: Opus 5 `high` — водитель сессии. Модель и effort
-  выставлять до первого сообщения; внутри сессии не переключать — сброс кэша.
+- Дефолт: Opus 5 `high` — водитель сессии. Модель и effort выставлять до
+  первого сообщения; внутри сессии не переключать — сброс кэша. `/model` и
+  `/effort` записывают выбор в `settings.json`, и следующая сессия стартует
+  с ним же: после сессии на Fable или с другим effort вернуть дефолт — это
+  отдельный шаг рядом с `/remember`.
```

### 2. Индекс памяти хуком, не прозой (уверенность высокая)

Строка «Load and follow global memory … at the start of every session» ничем
не проверяется и стоит отдельного хода; в сессии 2026-09-13 индекс в контекст
сам не попал. SessionStart-хук подаёт его детерминированно (≈600 токенов).

```diff
 ## Memory
-Load and follow global memory from `C:\Users\Vologdin\.claude\memory\MEMORY.md` at the start of every session, regardless of project.
+Индекс глобальной памяти `C:\Users\Vologdin\.claude\memory\MEMORY.md`
+подаётся хуком SessionStart. Файлы памяти открывать по ссылкам из индекса,
+когда задача их касается.
```

Новый `hooks/session-memory.ps1`: `Get-Content -Raw -Encoding utf8` файла
индекса, вывод через `ConvertTo-Json` (`hookSpecificOutput.additionalContext`),
как в `context-budget.ps1`. Регистрация в `settings.json`: событие
`SessionStart`.

### 3. Context7 против правила о справочных скиллах (уверенность средняя)

Инструкция сервера «use even when you think you know the answer» спорит со
строкой «справочные — только как источник фактов». Это «усилитель
тщательности» из статьи: лишние вызовы документации.

```diff
-Процессные скиллы обязательны, справочные — только как источник фактов
-(API, цены; не «на всякий случай» для вопросов без правки кода).
+Процессные скиллы обязательны, справочные (`claude-api`, context7) — только
+как источник фактов при правке кода под конкретный API или цены. Инструкция
+сервера context7 «use even when you think you know the answer» не действует:
+вопрос без правки кода документацию не тянет.
```
