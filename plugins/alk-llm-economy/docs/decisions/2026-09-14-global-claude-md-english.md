# 2026-09-14 — global/CLAUDE.md по-английски и без дублей

## Решение

`global/CLAUDE.md` переписан по-английски целиком, включая корпоративный
baseline, без кириллицы: правило «язык общения — русский» стоит первой
строкой, и напоминание о пропущенном шаге модель переводит сама. Размер 14 773 → 9 289 знаков
(207 → 191 строк).

Помимо перевода:

- правила, которые держат хуки (`context-budget`, `pause-guard`, `read-gate`,
  предел вывода Bash, строка модели на старте), сжаты до одной строки — хук
  сам говорит модели, что делать, когда срабатывает;
- ветка для L и `merge --no-ff` описаны один раз (были в трёх разделах),
  замер стоимости — один раз (был в двух);
- «Модели и effort» и «Уровни задач» стали таблицами; подробности цикла L
  (состав отчёта исполнителя, кто гоняет тесты) остались только в
  `docs/agent-prompts.md`, куда правило и отсылает;
- ссылки на `docs/` стали абсолютными: `~/.claude/docs` — junction на
  `ClaudeOps/docs`, `deploy.ps1` проверяет его наравне с `hooks/`.

## Зачем

Файл читается с каждого хода каждой сессии. Токенизатор режет кириллицу
примерно по 2,5 знака на токен, английский — по 4,3: та же норма по-английски
стоит в 1,7 раза меньше. Вместе с чисткой дублей оценка 5,9k → 2,2k токенов
на ход; при 9,3k ходов в неделю (аудит 09-14) это ≈ 35M токенов кэша,
≈ $17 в неделю на Opus 5 и вдвое больше на Fable. Мера 3 аудита (3a30f06)
резала только механику и дала 19,2k → 14,8k знаков; перевод — следующий шаг
того же аудита.

Точных токенов не мерили: `count_tokens` требует ключ консоли, а
`cache_read` первого хода за день плывёт из-за блока SessionStart (замечание
в handoff 09-14). Оценка по знакам с коэффициентами аудита.

## Границы

Чат остаётся русским: правило стоит первой строкой. Правила в переводе
сверены по пунктам с редакцией 5757fc9; при расхождении в поведении новой
сессии первым делом сравнивать с ней (`git show 5757fc9:global/CLAUDE.md`).

Baseline перестал совпадать с исходным корпоративным текстом дословно —
владелец на это пошёл сознательно: файл личный, общего источника у baseline
нет.

## Поправка, вечер 2026-09-14

Размер в этом решении оценивался по коэффициентам аудита (2,5 знака/токен для
кириллицы, 4,3 для английского) и вышел ≈2,2k токенов. Вечером того же дня
`/context` показал файл напрямую: **3,4k токенов** на 9 289 знаков, то есть
2,7 знака/токен, а не 4,3. Оценка занижена на треть.

Вывод не меняется — перевод всё равно окупился, — но коэффициент 4,3 для
английского завышен и в других расчётах аудита даёт слишком радужную картину.
Где важна цифра, а не порядок, размер берётся из `/context`, а не из знаков.
