# 2026-09-18. Ключ `model:` во frontmatter скилла: рычага для inline нет

Панель `/usage` советует: «heavy skills can be run with a cheaper model via
skill frontmatter». Проверяли ради `superpowers:writing-plans` — 20 % суток
2026-09-17, $15.32 за вызов. Если бы ключ работал в inline-форме, самый дорогой
скилл ехал бы на Haiku без единой правки процесса.

## Что измерено

Схема frontmatter лежит в бинаре 2.1.269 целиком: ключи `name`, `description`,
`model` («haiku, sonnet, opus, fable, or a full ID; `inherit` to match the
parent conversation»), `effort`, `context: inline|fork`, `agent`, `paths`,
`hooks`. Ни один скилл установленных плагинов ключом не пользуется
(`grep -rln --include='SKILL.md' '^model:'` — ноль файлов), поэтому проверяли
пробами: два скилла из одной строки текста, различающихся только `context`.

| Проба | frontmatter | Ход в транскрипте |
|---|---|---|
| `model-probe` | `model: haiku`, `context` по умолчанию (inline) | `claude-opus-5` |
| `model-probe-fork` | `model: haiku`, `context: fork` | `claude-haiku-4-5-20251001` |

Форк проверен по `<сессия>/subagents/agent-*.meta.json`: `agentType`
`general-purpose`, `model` `claude-haiku-4-5-20251001`, и обе строки хода в
`.jsonl` на той же модели.

## Вывод

Ключ применяется только при `context: fork`, то есть там, где скилл и так
выполняется сабагентом. Это ровно то же, что явный `model` в вызове `Agent`, —
новой экономии нет, есть форма записи: модель зашита в скилл, а не в промпт
вызывающего.

Для inline рычага нет и быть не должно: inline разворачивает скилл в текущий
разговор, смена модели там означала бы смену модели посреди сессии со сбросом
кэша — запрещено правилом в `global/CLAUDE.md`.

Практический итог для `writing-plans`: удешевить его frontmatter'ом нельзя.
Дешевле выходит своя тонкая замена, где исследование запрещено, а сабагенты
остаются только на проверку готового плана.

## Что осталось непроверенным

Соседние ключи той же схемы: `effort` (усилие на скилл), `paths` (скилл
грузится только при работе с подходящими файлами — прямой рычаг на цену
листинга) и `hooks`. Держится пунктом в `docs/tech-debt.md`.

Пробы `.claude/skills/model-probe*` удалены: каждая стоит места в листинге
каждой сессии, а результат записан здесь.
