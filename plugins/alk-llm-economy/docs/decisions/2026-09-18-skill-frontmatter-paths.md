# 2026-09-18. Ключ `paths:` во frontmatter скилла: рычаг работает, цена ему — центы

Продолжение пробы соседних ключей схемы (`2026-09-18-skill-frontmatter-model.md`,
пункт 27 в `docs/tech-debt.md`). Вопрос был один: правда ли скилл с `paths`
не попадает в листинг сессии, то есть не оплачивается чтением кэша на каждом
вызове API.

## Что измерено

Код 2.1.269. При загрузке скилл с непустым `paths` (и типом `prompt`) уходит
не в общий список, а в `conditionalSkills` — с отладочной строкой
«conditional skills stored (activated when matching files are touched)».
Обратно он попадает только через сверку пути файла: паттерны применяются
библиотекой `ignore`, то есть по правилам `.gitignore`, к пути **относительно
рабочей папки**; абсолютный путь вне неё (relative начинается с `..`)
пропускается молча. Паттерн `**` и хвост `/**` схлопываются: скилл с одним
`**` условным не становится.

Проба двумя скиллами из одной строки текста, различающимися только ключом:

| Проба | frontmatter | В листинге сессии |
|---|---|---|
| `paths-probe-ctrl` | без `paths` | появился сразу после создания файла |
| `paths-probe-cond` | `paths: ["**/*.zzz"]` | отсутствовал |
| `paths-probe-cond` | то же, после `Write` файла `probe.zzz` | появился |

Активация приходит отдельным сообщением в конце хода, а не правкой системного
промпта: кэш префикса она не рвёт. Скиллы подхватываются на лету, перезапуск
сессии для пробы не нужен.

## Сколько это стоит

Весь листинг — 8824 знака ≈ 2.2k токенов (`skill-usage.js --listing`,
2026-09-18). Он лежит в кэшируемом префиксе, поэтому цена = чтение кэша на
каждом вызове API: $0.5/MTok у Opus 5.

| Сессия | Вызовов | Цена всего листинга |
|---|---|---|
| рабочая крупная | 498 | ≈$0.55 |
| короткая | 46 | ≈$0.05 |

Четыре самых дорогих строки — `anthropic-skills` `docx`, `xlsx`, `pptx`, `pdf`
(3481 знак, 39 % листинга) ≈$0.22 за крупную сессию.

## Вывод

Рычаг настоящий, но мелкий: даже полное исчезновение листинга экономит меньше
доллара в сутки, а реально доступные к сужению строки — четверть доллара.
Своих скиллов у нас нет, сужать нечего; четыре дорогие строки живут в
`~/.claude/plugins`, где правка переживает ровно до обновления плагина, и
сужение по `paths` отняло бы у них главный сценарий — «сделай .docx с нуля»,
когда подходящего файла ещё не существует.

Правило: ключ `paths` применять в своих скиллах, привязанных к формату файлов,
и не трогать ради него чужие. Для чужих дорогих скиллов рычаг другой —
отключение (`docs/plugins.md`), и оно требует ответа, нужны ли они вообще.

Остались непроверенными `effort` и `hooks` из той же схемы; `model` и `paths`
закрыты. Пробы `.claude/skills/paths-probe-*` удалены: каждая стоит места
в листинге каждой сессии.
