# 2026-09-15 — по порогу контекста сжимать, а не перезапускать сессию

## Решение

Выход по порогу бюджета контекста — `/compact` в той же сессии, не новая
сессия с handoff. Хук `hooks/context-budget.ps1`:

- пропускает `/compact` через красную блокировку так же, как `/remember`;
- в жёлтом тексте (100k) просит модель предложить владельцу «сжать контекст /
  продолжаем здесь» и дать строку `/compact` с фокусом по шаблону handoff;
- в красном тексте (150k и каждые 100k дальше) называет сжатие дешёвым выходом;
- при контексте ниже 100k удаляет флаги порогов этой сессии: сжатие —
  единственное падение контекста внутри сессии, без сброса второй набор до
  100k прошёл бы молча.

Фокус для сжатия — одна строка в `global/CLAUDE.md`, владелец набирает её
после `/compact`: секции для этого в CLAUDE.md у Claude Code нет.

Уточнение 2026-09-16, второй заход (`docs/compaction.md`): первая половина
той фразы тоже требует оговорки. Разбора секции в бинаре нет, но сжатие идёт
с тем же системным промптом, куда CLAUDE.md вшит, — правило про сжатие,
записанное там, влияет на сводку и не отменяет предрасчитанную заготовку,
в отличие от ручной строки и хука. Рабочий порядок теперь такой:
правило в CLAUDE.md, ручная строка — только для разового фокуса.

Уточнение 2026-09-16, разбор бинаря 2.1.269 (`docs/compaction.md`): вторая
половина той фразы — «инструкции принимает только аргумент команды» — неверна.
В тот же блок `Additional Instructions:` попадает stdout хука PreCompact, так
что постоянный фокус задаётся хуком и действует на автосжатии тоже. Решение
не меняется до замера: хук, судя по коду, отменяет предрасчитанную сводку и
может стоить дороже ручной строки (`docs/tech-debt.md` п. 21).

Новая сессия остаётся для смены модели или effort и для конца дня.
`/remember` по-прежнему без блокировки.

Тесты: `hooks/context-budget.test.ps1`, 7 новых случаев.

## Зачем

По цене хода варианты равны: и сжатие, и закрытие сессии — один ход на полном
контексте (кэш читается по цене чтения) плюс несколько тысяч токенов сводки.
После сжатия контекст ≈ старт новой сессии: системный промпт, CLAUDE.md,
индекс памяти (SessionStart с матчером `compact` срабатывает) и сводка.

Разница в потерях, а не в токенах:

- сводку пишет модель, которая видела всё, а не Haiku по выжимке скрипта;
  handoff 2026-09-15 уже терялся и восстанавливался из транскрипта;
- сессия не перезапускается: модель и effort не слетают, `settings.json`
  восстанавливать не нужно;
- пауза больше часа после сжатия стоит копейки — префикс маленький;
- транскрипт остаётся в том же `.jsonl` (id сессии не меняется), выжимку из
  него при нужде даёт `handoff-from-transcript.js`; сырой транскрипт в
  контекст по-прежнему не читается.

Правило «тупик → `/rewind`, не `/compact`» не противоречит: там есть
кэшированная точка возврата, на пороге её нет — оба пути строят новый префикс.

## Границы

- Не включать во время замеров 1 и 2 пакета Batch: протокол замера считает
  шов сессии на 120k и avg водителя по каждой сессии отдельно. Ветка
  `feat/compact-at-threshold` сливается после замера 2, тогда же деплой
  `global/CLAUDE.md`.
- Первую сессию со сжатием замерить в `docs/costs.md`: правило не
  калибровано, пока нет строки.
- Хук PreCompact не строится ради протокола: «протокол в файл» уже есть —
  сам `.jsonl`. Как носитель постоянного фокуса сжатия он стал кандидатом,
  но только после замера цены (`docs/tech-debt.md` п. 21).
- Точечное восстановление из транскрипта (grep по выжимке вместо replay) —
  отдельный пункт, схема работает и без него.
