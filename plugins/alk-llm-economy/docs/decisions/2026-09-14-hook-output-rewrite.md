# Rewrite вывода инструмента отдаётся в форме этого вывода

2026-09-14

## Что решено

Хук `PostToolUse`, подменяющий вывод Bash (`hooks/test-output-filter.ps1`),
возвращает `updatedToolOutput` объектом `{ stdout, stderr, interrupted,
isImage }`, а не строкой. Сводка кладётся в `stdout`, `stderr` обнуляется,
остальные поля переносятся из исходного вывода.

## Почему

Claude Code сверяет `updatedToolOutput` со схемой вывода инструмента и, если
форма не сошлась, молча откатывает подмену к оригиналу: сообщение
`PostToolUse hook returned updatedToolOutput that does not match <tool>'s
output shape` уходит в UI, а агент получает исходный вывод и не знает, что
хук вообще работал. У Bash вывод — объект, поэтому строка отбрасывалась
всегда.

Как проверялось (сессия 2026-09-14, Claude Code 2.1.270):

1. Хук временно писал рядом с логом то, что печатал на stdout. В боевом
   прогоне он строил верную сводку (313 байт из 3309) и печатал корректный
   ASCII-JSON — а модель получала полный вывод. Значит дело не в хуке.
2. Строка на верхнем уровне ответа вместо `hookSpecificOutput` — тот же
   результат: форма ответа ни при чём, отвергался сам тип значения.
3. Объект `{ stdout, stderr, interrupted, isImage }` — сводка пришла
   вместо вывода с первого прогона.

Первая редакция хука опиралась на обратное утверждение («строкой, никогда не
объектом, иначе перепишется `exit_code`»). Оно не проверялось боевым
прогоном: в сессии, где хук писали, он не запускался вовсе — хуки снимаются
при старте сессии, и внешняя правка `settings.json` к идущей сессии не
применяется. Код возврата при объектной форме доходит до агента: красный
прогон в живой сессии сохранил `EXITCODE=1`.

## Что из этого следует

- Хук, подменяющий вывод любого инструмента, проверяется только в сессии,
  запущенной после его регистрации, и только по боевому прогону. Совпадение
  фикстурных тестов ничего не говорит о том, применит ли подмену харнесс.
- Откат подмены не виден агенту. Если сводка не пришла — смотреть, дошёл ли
  хук до печати (запись stdout в файл рядом с логом), а не править эвристику.
