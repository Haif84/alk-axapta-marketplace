# 2026-09-14 — схемы неиспользуемых инструментов вынуты из промпта

## Решение

В `~/.claude/settings.json` добавлен `permissions.deny`:

```json
"deny": ["Artifact", "Workflow", "NotebookEdit", "ScheduleWakeup"]
```

Запрет снимает схему инструмента из системного промпта, а не только запрещает
вызов. Боевой эффект — **−20 928 токенов на каждом ходу** любой сессии.

## Замер

Прогоны `claude -p "ok" --model haiku --output-format json` в пустой папке,
считается полный промпт: `input + cache_creation + cache_read`.

| Прогон | полный промпт | Δ |
|---|---|---|
| без изменений | 43 306 | — |
| `--disallowedTools NoSuchToolXyz` (контроль) | 43 305 | −1 |
| `--disallowedTools Bash` (контроль) | 43 306 | 0 |
| `--disallowedTools Workflow` | 37 016 | −6 290 |
| `--disallowedTools Artifact` | 29 926 | −13 380 |
| `--disallowedTools Artifact,Workflow` | 23 638 | −19 668 |
| `--settings` с `permissions.deny` тех же двух | 23 639 | −19 667 |
| + `NotebookEdit`, `ListAgents`, `ScheduleWakeup` | 22 067 | −21 239 |
| + `PowerShell`, `AskUserQuestion`, `Skill` | 17 304 | −26 002 |
| **боевой прогон на принятом наборе** | **22 378** | **−20 928** |

Два контроля отделяют эффект от шума: несуществующее имя не меняет ничего,
запрет `Bash` не меняет ничего — базовые инструменты остаются в промпте всегда.
Значит убыль даёт именно снятие схемы, и складывается она аддитивно
(13 380 + 6 290 = 19 670 против измеренных 19 668).

`permissions.deny` в настройках даёт тот же результат, что флаг CLI
(23 639 против 23 638) — рычаг раскатывается штатно, патчи плагинов не нужны.

## Зачем

Схемы инструментов — 38,3k из 97,3k контекста в замере сессии Batch, больше
трети, и читаются на каждом ходу. Два инструмента из них дают половину: у
`Artifact` и `Workflow` описания на несколько тысяч токенов каждое, а за
14 сентября в Batch и ClaudeOps ни один не вызван ни разу.

Деньги для Batch за 14 сентября (804 хода, 16 стартов, Opus 5: чтение кэша
$0.50/M, запись $6.25/M): чтение 16,8M токенов — $8.42, запись 0,33M — $2.09.
Порядка $10 в день на один проект.

## Что не запрещено и почему

- `ListAgents` — 5 вызовов за день, инструмент живой.
- `ReportFindings` — им отдаёт находки `/code-review` из обязательного цикла.
- `Skill`, `AskUserQuestion` — обязательные скиллы фаз и правило «спрашивать на
  развилке». Вместе с `PowerShell` дали бы ещё 4,1k, но это правила цикла.

## Что теряем и как вернуть

`Artifact` — публикация HTML-страниц на claude.ai. `Workflow` — оркестрация
сабагентов скриптом. `NotebookEdit` — `.ipynb`, таких проектов нет.
`ScheduleWakeup` — самостоятельный темп в `/loop`.

Возврат на одну сессию: `claude --allowedTools Workflow`. Возврат совсем —
убрать имя из `deny`.

Связь с техдолгом 11: там одним из вариантов пилота было гонять цикл SDD
инструментом `Workflow`, и ради него запрет пришлось бы снять. 2026-09-16
владелец выбрал другой вариант — водитель читает у рецензента одну строку
вердикта, — так что `Workflow` остаётся запрещённым: его схема в каждом ходу
водителя вошла бы в замер пакета чужим расходом.

## Как перепроверить

Из пустой папки прогнать `claude -p "ok" --model haiku --output-format json` и
сравнить сумму `input + cache_creation + cache_read` с числами выше. Прогон
разовый, стоит копейки на Haiku; повторить после крупного обновления CLI —
состав встроенных инструментов меняется вместе с ним.
